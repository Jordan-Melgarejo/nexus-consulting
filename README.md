# Nexus Consulting — Plataforma Corporativa & Dossier Ejecutivo

> Sitio web corporativo de alta fidelidad y dossier interactivo para firma de consultoría estratégica, optimización de procesos y transformación empresarial.

---

## 📌 Descripción del Proyecto

Nexus Consulting es una plataforma web desarrollada con un estándar estético de nivel agencia internacional. Presenta una arquitectura modular, navegación fluida, tipografía editorial y un dossier ejecutivo interactivo de 2 páginas con soporte para exportación o visualización inmersiva.

### 🌟 Módulos y Experiencia

1. **Portal Corporativo:**
   - Presentación de pilares estratégicos y servicios clave (Estrategia, Transformación, Métricas).
   - Componentes interactivos con microanimaciones CSS de alto rendimiento.
   - Navegación responsive optimizada para dispositivos móviles y comités ejecutivos.

2. **Dossier Ejecutivo Interactivo:**
   - Resumen de credenciales y metodología de consultoría.
   - Panel de contacto confidencial para niveles C-Suite.
   - Estilo editorial con vectores SVG optimizados.

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 Semántico, CSS3 Moderno (Custom Properties, Grids fluidos, Efectos Glassmorphism), JavaScript Moderno (Vanilla ES6+).
- **Diseño & Rendimiento:** Cero dependencias externas pesadas, carga instantánea y SEO semántico completo (Schema.org / JSON-LD).
